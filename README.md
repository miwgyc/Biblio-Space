## Project Overview

Biblio-Space is a web-based Student Library Room Booking System designed to make the process of reserving library study rooms easier and more organised.

The system allows students to register, log in, view available study rooms, make reservations, and manage their bookings. Librarians can monitor student reservations, view daily booking schedules, and manage room availability.

## Project Objectives

- To simplify the library room booking process.
- To allow students to manage their room reservations.
- To help librarians monitor booking activities.
- To provide an organised platform for managing library study spaces.

## System Features

### Student
- Student registration and login.
- View available study rooms.
- Book a study room.
- View personal bookings.
- Cancel existing bookings.
- View booking confirmation details.

### Librarian
- Librarian login.
- View total bookings.
- Monitor room utilisation.
- View daily student booking schedules.
- Manage room availability and maintenance status.

## Project Structure

- `index.html` – Homepage
- `login.html` – Login page
- `register.html` – Student registration page
- `student-dashboard.html` – Student dashboard
- `booking.html` – Room booking page
- `confirmation.html` – Booking confirmation page
- `my-bookings.html` – Student booking records
- `librarian-dashboard.html` – Librarian dashboard
- `daily-schedule.html` – Daily booking schedule
- `manage-rooms.html` – Room management page
- `style.css` – Website styling
- `script.js` – Booking system functionality
- `portal.js` – Login, dashboard and portal functionality

## Project Limitations

This project currently uses browser Local Storage to store registration details, room information and booking records. It does not yet use a central database.

## Conclusion

Biblio-Space aims to provide a convenient and organised room booking experience for students while helping librarians manage library study spaces more efficiently.
