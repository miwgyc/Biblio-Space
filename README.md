# Biblio-Space – Student Library Room Booking System

## 1. Project Overview

Biblio-Space is a web-based Library Discussion Room Booking System designed to make the process of reserving library study rooms easier and more organised.

The system allows students to register, log in, view available study rooms, make reservations, and manage their bookings. Librarians can monitor student reservations, view daily booking schedules, and manage room availability.

## 2. Project Objectives

- To simplify the library room booking process.
- To allow students to manage their room reservations.
- To help librarians monitor booking activities.
- To provide an organised platform for managing library study spaces.
- To improve the efficiency of library room management.

## 3. System Features

### Student Module

- Student registration and login.
- View available study rooms.
- Book a study room.
- View personal booking records.
- Cancel existing bookings.
- View booking confirmation details.
- Monitor weekly booking hours.

### Librarian Module

- Librarian login.
- View total bookings.
- Monitor room utilisation.
- View daily student booking schedules.
- View student booking details.
- Manage room availability.
- Update room maintenance status.

## 4. Technologies Used

- **HTML** – Website structure.
- **CSS** – Website styling and layout.
- **JavaScript** – System functionality and interactions.
- **Java Web Application** – Project environment.
- **NetBeans IDE** – Development environment.
- **GlassFish Server 4.1.1** – Application server.
- **Browser Local Storage** – Temporary storage for user accounts, room information and booking records.

## 7. How to Run the System

1. Download or clone this repository from GitHub.
2. Open the project using NetBeans IDE.
3. Make sure GlassFish Server 4.1.1 is configured in NetBeans.
4. Run the web application using GlassFish Server 4.1.1.
5. Open the application in a web browser.
6. Register a new student account or log in using the demo credentials provided above.
7. Explore the available features based on the selected user role.

## 9. Project Limitations

This project currently uses browser Local Storage to store student registration details, room information and booking records.

It does not yet use a central database. Therefore, the stored information is limited to the browser and website origin where the system is accessed.

## 10. Conclusion

Biblio-Space aims to provide a convenient and organised room booking experience for students while helping librarians manage library study spaces more efficiently.

The system demonstrates the basic functionality of a library room booking platform through separate student and librarian modules.
